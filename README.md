# 👁️ Live AI Face Tracker

A lightweight, real-time computer vision script that detects human faces through a live webcam feed. Built as a foundational exploration into AI vision models ahead of HackFest 2026.

## ⚙️ Tech Stack
* **Language:** Python
* **Library:** OpenCV (`cv2`)
* **Model:** Pre-trained Haar Cascade Classifier

## 🚀 How to Run Locally
1. Clone this repository.
2. Install dependencies: `pip install "opencv-python<5"`
3. Run the script: `python face_tracker.py`
